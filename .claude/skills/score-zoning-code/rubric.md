# ZoneCo Equitable Zoning Scorecard (original version) — grading rules

Where these sections disagree, the "Rulings from Sean Suder" at the end win.

Scoring: start at 0. Within a category, EVERY line whose condition is true is scored, and the points ADD UP (e.g. parking minimums in residential zones -1 AND in commercial zones -0.5 = -1.5). Lines that are not true score 0. Total = sum of all lines. Bands: > +5 Very Positive; 0 to +5 Positive; below 0 to -5 Negative; < -5 Very Negative.

Working definitions (confirmed/assumed by ZoneCo):
- "Residential zone" = a base zone whose primary purpose is housing. Mixed-use zones count as COMMERCIAL, not residential. Overlays are ignored unless they replace base standards.
- "Mixed-use within building" = housing plus a non-residential use in the same building.
- "By right" = permitted with administrative/staff review only; conditional use, special use/exception, or any public-hearing approval is NOT by right.
- Bonus points require the use to be permitted BY RIGHT (a special permit only = 0).
- ADUs banned in single-unit zones but allowed elsewhere = 0 for the ADU category.
- Ignore lot-size rules tied only to septic leach fields. Ignore heights for appurtenances and telecom towers.

## Core categories
1. Residential Unit Density
   a. At least one zone or district applies a maximum residential unit density standard: -1
   b. No density maximum in all residential zones: +0.5
   c. Minimum density in some residential zones: +1
2. Lot Area
   a. Minimum lot size of 5,001+ sf (in any zone): -1
   b. Minimum lot size under 5,000 sf: +0.5   (i.e. minimum lot sizes exist but all are under 5,000 sf)
   c. No minimum lot size: +1
3. Residential Unit Size
   a. At least one zone requires a minimum residential unit size: -1
   b. No minimum unit size: +1
4. Heights (Multi-unit residential buildings)
   a. Maximum height for multi-unit buildings: -1
   b. No maximum heights for multi-unit buildings: +1
5. Heights (Commercial/Mixed-Use)
   a. More than half of commercial and/or mixed-use zones limit maximum heights: -1
   b. More than half (but less than all) of commercial/mixed-use zones do not limit maximum heights: +0.5
   c. All commercial/mixed-use zones do not limit maximum heights: +1
6. Multi-unit Residential (3+ units)
   a. Prohibited in all zones: -1
   b. Permitted in some zones, or only as conditional in some/all zones: -0.5
   c. Permitted by-right in commercial zones: +1
   d. Permitted by-right in all residential zones: +1
7. Mixed-use within building
   a. Not permitted in any zone: -1
   b. Permitted in only some zones: -0.5
   c. Permitted in all zones: +1
8. ADUs
   a. Prohibited in all zones: -1
   b. Permitted in single-unit residential zones: +1
9. Parking
   a. Off-street parking minimum applies in residential zones: -1
   b. Off-street parking minimum applies in commercial zones: -0.5
   c. No off-street parking minimum in residential zones: +0.5
   d. No off-street parking minimum in commercial zones: +1

## Bonus points
10. Design Review: no design or architectural review public hearing process for residential buildings: +0.5
11. Residential Occupancy Language: code does not use the term "family" or "unrelated" (to limit occupancy): +0.5
12. Home Occupations: permits home occupations: +0.5
13. Childcare: allows childcare within residential neighborhoods (by right): +0.5
14. Educational Facilities: allows educational facilities in residential zones (by right): +0.5
15. Assisted Living: allows assisted living uses in residential zones (by right): +0.5

## Rulings from Sean Suder (Oct 2026)
1. Stacking: "permitted in only some zones" (6b, 7b) still applies even when a positive line in the same category also applies.
2. "In residential zones" / "in commercial zones" means ALL zones of that type (all residential / all commercial-and-mixed-use base zones).
3. A design/architectural review public hearing counts against line 10 even if it applies only in a historic or architectural-review overlay district.
4. Line 11: the bonus is lost only if the code actually caps how many unrelated people may live together (a definition that is never applied does not count).
5. Small-scale versions of a use (e.g., home daycare, small group homes required by state law) earn the bonus if they are allowed by right.
6. A code with only parking MAXIMUMS has "no off-street parking minimum."
7. Townhomes (3+ attached units, including on separate lots) count as multi-unit (3+ units).
8. Agricultural zones (e.g., UA, R-AG) are "other," not residential, even if the code labels them residential (confirmed by Sean).
