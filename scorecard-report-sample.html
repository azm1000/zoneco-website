How the score works

Every code starts at zero. Each of nine core categories adds or subtracts points depending on whether the code creates scarcity (large minimum lots, height caps, parking minimums, housing types banned by zone) or abundance (more housing types allowed by right, no minimum unit sizes, no parking minimums). Six bonus categories add up to half a point each. Scores range from about −10 to +15.

Bands: above +5 is Very Positive, 0 to +5 Positive, below 0 to −5 Negative, and below −5 Very Negative.

What this report is, and is not

This is a preliminary, automated assessment of the document you provided, using ZoneCo's Equitable Zoning Scorecard. It does not account for how much of the community's land is mapped in each zone, amendments not included in the document, or how the code is administered in practice.
